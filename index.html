WHY CREATORPROOF

Protection starts with proof.

Simple tools to create a verifiable digital record of your creative work.

THE PROBLEM

Creators need a verifiable record that a particular digital file existed when it was registered.

THE SOLUTION

CreatorProof generates a SHA-256 fingerprint and records it through a Solidity smart contract on Sepolia. Anyone can check a file's fingerprint using public, read-only verification.

TECHNOLOGY

HTML, CSS, JavaScript, ethers.js v6, Solidity, MetaMask for signing registration transactions, and the Ethereum Sepolia testnet.

LIMITATIONS

The system records and verifies file hashes. It does not guarantee legal copyright ownership or prevent copying.
